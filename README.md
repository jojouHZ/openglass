# OpenGlass

Zero-knowledge secure messenger with ephemeral private layer and regular public layer.

## Overview
OpenGlass is a privacy-focused messenger built with Go backend and Vue3+Vite frontend using MFE architecture.

## Features
- Email-based registration with one-time code
- Public layer for regular messaging
- Private layer for ephemeral, zero-knowledge conversations
- PWA cross-platform experience (MVP)
- E2EE and zero-knowledge architecture

## Tech Stack
- **Backend:** Go with WebSocket relay
- **Frontend:** Vue3 + Vite (MFE architecture)
- **MVP:** PWA (Progressive Web App)
- **Future:** iOS, Android, Desktop, macOS

## Agent System
OpenGlass uses a hierarchical agent system with 14 specialized agents organized in 4 layers.

See [AGENTS.md](AGENTS.md) for detailed agent information.

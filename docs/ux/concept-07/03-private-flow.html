03 · Private session in the same window

The conversation never changes screen. For an unverified contact the header shows a lock instead of the switch; tapping it runs the device-bound verification ritual (5 symbols / QR). Once verified, the switch appears and opens a settings sheet (not a new screen); after the peer accepts, the chrome flips to the private palette, the 5-symbol check unlocks messaging and the view-once switch (a lock sits in its place until then), and ending the session erases private bubbles in place.
